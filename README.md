This project is a modern and responsive landing page designed for the MagSafe Wallet Pro with Stand for iPhone. The page is built using HTML, CSS, and Vanilla JavaScript, without relying on heavy frameworks. It focuses on minimalism, smooth animations, and mobile-first design principles.

Key Sections in the Code:
Hero Section: Bold introduction to the product with a call-to-action and scroll animation.

Feature Highlights: Clearly laid out product benefits using icons and short text.

Pair It With Products: Displays 3 premium accessories that complement the MagSafe Wallet, styled with cards and hover animations.

FAQ Section: Built with JavaScript to allow toggling of answers interactively.

Testimonials Section: Customer reviews presented in clean, responsive cards with subtle effects.

Call to Action (CTA): Includes a short “About Me” description and button for user engagement.

JavaScript Functionality:
FAQ toggle animation (accordion-style).

Custom animations using AOS (Animate On Scroll) for smooth section reveals.

Card animation on scroll and hover for visual engagement.

Responsive Design:
Fully responsive layout using CSS Flexbox and media queries.

Optimized for mobile, tablet, and desktop screens.

Smooth scroll behavior and adaptive font sizes.

This project demonstrates best practices in frontend development while keeping it lightweight, fast-loading, and visually appealing.
